# Us

This app is for counting how long we've been together.

## Customization

If you want to use this for yourself:

1.  **Background Photos**: Upload your own `mobile_background.jpg` and `desktop_background.jpg` to the `public/` folder.
2.  **Start Date**: Change the start day in `components/elapsed-time.tsx`. Look for the `startDay` variable.

## Getting Started

First, run the development server:

```bash
npm run dev
# or
yarn dev
# or
pnpm dev
# or
bun dev
```

Open [http://localhost:3000](http://localhost:3000) with your browser to see the result.
